Política de privacidade do Claudinho

Atualizada em 02/11/2026.

O Claudinho é um assistente de uso particular de Anthony Duarte. Ele não é oferecido a outras pessoas e só acessa as contas do próprio dono, depois que ele autoriza.

O que o app acessa

  • Gmail, somente leitura: ler e buscar os e-mails do dono e baixar anexos, para resumir e organizar. O app não envia, não apaga e não altera e-mails.
  • Google Drive, só os arquivos criados pelo app: guardar as cópias de segurança do dono. O app não vê os outros arquivos do Drive.

Como os dados são usados

Os dados são usados só para servir o próprio dono. Nada é vendido, compartilhado com terceiros nem usado para publicidade. O uso das informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Onde ficam

As informações ficam no computador e no servidor particular do dono. Os tokens de acesso ficam guardados em arquivos protegidos e podem ser revogados a qualquer momento em myaccount.google.com/permissions.
